# Rava Dictionary 1.0.0

First public macOS release. Search English, Persian, and German in six
directions, fully offline. Includes a native Mac interface, saved words,
pronunciation using macOS voices, and a custom app icon.

German–Persian translations are inferred through English. The app displays
the bridge word and marks these results for checking; ambiguous words may
produce inaccurate translations.

Requires macOS 13 or later. The app is ad hoc signed, not notarized with an
Apple Developer ID. The packaged dictionary combines Openjam (MIT) and
WikDict (CC BY-SA 4.0) data; see the attribution files in the repository and
app bundle.
